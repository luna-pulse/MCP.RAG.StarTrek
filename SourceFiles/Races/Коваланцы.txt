# Коваланцы
Оригинальное название: Kovaalan

####
Общие сведения:
Коваалцы — раса из Бета-квадранта.
Ковааланы были агрессивной и территориальной, технологически развитой расой, которая контролировала туманность в Дельфийском пространстве в 22 веке, в которой находился один конец подпространственного коридора.
В 2154 году, пытаясь использовать коридор для встречи с зинди-приматом Дегрой, экипаж «Энтерпрайза NX-01» был вынужден сражаться с несколькими звездолетами Коваала. С помощью своих коллег из смещенной во времени версии «Энтерпрайза» из альтернативной временной шкалы команда смогла успешно пройти мимо ковааланцев и безопасно пройти через коридор. (ENT: "E²")
