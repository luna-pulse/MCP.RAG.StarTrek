# intfloat/multilingual-e5-small

Файлы в `Models/multilingual-e5-small/` скачаны из официального репозитория модели на Hugging Face:

<https://huggingface.co/intfloat/multilingual-e5-small>

| Файл | Откуда |
|---|---|
| `tokenizer.json` | <https://huggingface.co/intfloat/multilingual-e5-small/resolve/main/tokenizer.json> |
| `model.onnx` | <https://huggingface.co/intfloat/multilingual-e5-small/resolve/main/onnx/model.onnx> |

Карточка модели указывает лицензию **MIT** (`license: mit`). Проект E5, из которого эта модель, лежит в репозитории Microsoft UniLM и распространяется по лицензии MIT: <https://github.com/microsoft/unilm/blob/master/LICENSE>. Текст этой лицензии приведён ниже.

Авторы: Liang Wang, Nan Yang, Xiaolong Huang, Linjun Yang, Rangan Majumder, Furu Wei. Отчёт: [Multilingual E5 Text Embeddings](https://arxiv.org/pdf/2402.05672), arXiv:2402.05672, 2024.
